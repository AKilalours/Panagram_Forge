# Model card

To be completed at the end of Phase 3 and updated at each release. Required sections:
intended use, out-of-scope use, training data version, evaluation results across all
five regimes plus external benchmarks, calibration, known failure modes taken from the
Failure Atlas, and the operating threshold with its FPR budget.

Explicit out-of-scope statement to carry from day one: FORGE is a research system. It
must not be used as sole evidence in an academic misconduct or employment decision.
